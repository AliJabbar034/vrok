vrok vs ngrok and WeTransfer

ngrok exposes a port. WeTransfer uploads a copy. vrok gives someone a temporary link to what is already on your machine: a file, a folder or a running app. Here is when each one fits.

At a glance

If you need vrok ngrok / tunnels WeTransfer / file hosts
Share a running localhost app Yes, vrok localhost:3000 Yes, their main job No
Share a file or folder directly Yes, with previews Only if you run a file server Yes, by uploading a copy
No account Yes Account required Depends on the service
Link that expires or works once TTL, download limit, password Stays up until you stop it Expires after their retention period
Recipient can get it after you go offline No, by design No Yes, their main job

Choose vrok when

  • Someone needs what is on your machine now, and should not have it tomorrow.
  • You want one tool for files, folders and localhost.
  • You would rather not create an account or upload anything.
  • You want the code: vrok is MIT licensed, and you can run your own relay.

Choose something else when

  • ngrok or another tunnel service: you need a long-lived tunnel, a reserved domain, or request inspection and traffic policies.
  • WeTransfer or a file host: the recipient must still have the file after your computer is off.

Questions

Is vrok a free alternative to ngrok?

For sharing a localhost app with someone, yes: free, open source and no account. For long-lived production tunnels with reserved domains, ngrok is built for that.

Is vrok an alternative to WeTransfer?

For sending files while you are online, yes, and without uploading them or any size limit. If the recipient needs the file after you go offline, use a file host.

Does vrok use Cloudflare?

By default it opens a free Cloudflare quick tunnel, with no Cloudflare account. You can keep shares on your network with --local, or run your own relay.

Is vrok open source?

Yes, MIT licensed, on GitHub.

Install vrok

One command on macOS and Linux. Free, MIT licensed, no account.

curl -fsSL https://raw.githubusercontent.com/AliJabbar034/vrok/main/install.sh | sh

Windows, Homebrew, Scoop, winget and Linux packages are on the download page. Every command and flag is in the guide.
