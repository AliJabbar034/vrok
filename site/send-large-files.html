vrok / Send large files

Send large files without uploading them

Uploading a big file to a transfer service means waiting for the upload, then waiting again while they download. vrok skips the upload: the other person downloads straight from your machine.

In one command

Point vrok at the file, or at a whole folder:

vrok ./launch-cut.mov

The link is ready at once and copied to your clipboard. They can watch a video in the browser with seeking, or download the original bytes.

Built for big transfers

  • No size limit. Nothing is uploaded, so there is no quota. The limit is your disk.
  • Resumable. A dropped download continues where it stopped.
  • Live progress. Your terminal shows how far they have got, the speed and the time left.
  • Your computer stays awake while someone is downloading.
  • A SHA-256 fingerprint on the download page, so they can check the copy is intact.
  • Whole folders download as one zip, built while it is sent.

Control who gets it

  • --downloads 1 makes it a one-time link.
  • --password asks for a password first.
  • --ttl 1d closes the link after a day. Otherwise it lasts until you stop it.

Speed depends on your upload bandwidth, since every byte comes from your machine. Keep vrok running until they have finished.

Questions

How do I send a file that is too big for email?

Run vrok ./bigfile.zip and send the link it prints. The file is served from your computer, so there is no attachment limit and no upload.

Is there a file size limit?

No. vrok streams the file from disk, so a 50 GB file works the same as a 5 MB one. Transfer speed is set by your upload bandwidth.

What if the download is interrupted?

It resumes. Browsers and download managers continue from where they stopped, and resuming does not use up a download from --downloads.

Does my computer need to stay on?

Yes, while they download. vrok keeps the machine from sleeping on its own during a transfer. If they need the file after you switch off, a file host is the better tool.

Install vrok

One command on macOS and Linux. Free, MIT licensed, no account.

curl -fsSL https://raw.githubusercontent.com/AliJabbar034/vrok/main/install.sh | sh

Homebrew, Scoop, Windows, Linux packages and verified archives are on the download page. Every command and flag is in the guide.
