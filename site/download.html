Collection point

Free and open source. One self-contained binary. No runtime, no account, nothing to configure.

Latest release loading…

One command

curl -fsSL https://raw.githubusercontent.com/AliJabbar034/vrok/main/install.sh | sh

Or Homebrew, once the tap is published

brew install --cask AliJabbar034/tap/vrok
curl -fsSL https://raw.githubusercontent.com/AliJabbar034/vrok/main/install.sh | sh

Or from source

go install github.com/AliJabbar034/vrok/cmd/vrok@latest

.deb, .rpm and .apk sit on the release page.

irm https://raw.githubusercontent.com/AliJabbar034/vrok/main/install.ps1 | iex

Once published, winget

winget install AliJabbar034.vrok

Or Scoop — add the bucket, then install

scoop bucket add vrok https://github.com/AliJabbar034/scoop-bucket

Then what

Update
Run the install command again. It overwrites the binary with the newest release. Homebrew: brew upgrade --cask AliJabbar034/tap/vrok. From source: go install …/cmd/vrok@latest. Then vrok --version.
Check it
vrok --version
Share something
vrok ./quarterly.pdf — prints a public URL that works until you stop it.
See what is open
vrok list · vrok revoke <id>
Build from source
go install github.com/AliJabbar034/vrok/cmd/vrok@latest
